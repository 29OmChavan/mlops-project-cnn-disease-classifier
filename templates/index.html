Caveat on PyTorch Dynamic Quantization (`quantize_dynamic`): Calling torch.quantization.quantize_dynamic(model, {nn.Linear}, dtype=torch.qint8) only quantizes the final linear classification head (`nn.Linear`), leaving the `nn.Conv2d` backbone weights in FP32. That is why the file size on disk only drops slightly (~42.7 MB to ~41.9 MB), even though CPU linear head dispatch still gets faster. Full Conv2d INT8 requires static post-training calibration (`prepare` + calibration loader + `convert`).

Developer Notes: Why This Repo Exists & How It Was Built Git Tag: v2.0.0

Most image classification tutorials stop the moment `model.fit()` finishes in a Jupyter notebook. When I built this poultry disease classifier (based on Krish Naik's DVC pipeline structure and Andrej Karpathy's backprop lectures), I wanted a repo where `dvc repro` actually runs end-to-end from a cold clone without hard-coded local paths.

The dataset covers four classes of poultry fecal microscopy crops: Coccidiosis, Salmonella, Newcastle Disease, and Healthy. A single misclassified Newcastle slide is a big deal because it triggers flock quarantine, whereas a noisy blurry photo shouldn't set off a false alarm. That is why I added 6-pass Test-Time Augmentation (flipping the image horizontally/vertically, tweaking contrast/brightness, and running a 0.6px Gaussian blur) to measure how much the softmax probability wobbles across views. If the standard deviation across those 6 views jumps above 8.5%, or top confidence drops below the user's cutoff, the app flags the slide for manual lab review instead of guessing.

Repository Layout & Engineering Notes

src/cnn_classifier/components/prepare_base_model.py Contains both the pure NumPy `conv2d_from_scratch` loop, a custom `FirstPrinciplesResidualBlock` with skip connections, and the `DiseaseClassifierTransferNet` wrapper around `resnet18`.
src/cnn_classifier/components/clinical_cv_suite.py Implements input-gradient saliency maps (smoothed with two passes of a 3x3 Gaussian filter), 6-view TTA variance, SNR/Laplacian sharpness checks, and `ScalarValue` reverse-mode autograd.
dvc.yaml & params.yaml Splits the workflow into 4 stages (`data_ingestion`, `prepare_base_model`, `training`, `evaluation`). Running `dvc repro` only re-executes stages whose code or hyperparameters changed.
app.py FastAPI server supporting both Krish Naik's JSON base64 payload (`POST /predict`) and multipart file uploads (`POST /predict-upload`).

Help & Step-by-Step User Manual Operator Guide

1. How to Screen a Single Microscopy Slide (Tab 1: Slide Workbench)

  • Using built-in samples: Click any of the quick sample buttons (`Coccidiosis`, `Healthy`, `Newcastle_Disease`, `Salmonella`) on the left panel, or select one from the dropdown and click Run Slide Screening.
  • Uploading your own image: Click Choose File under "2. Or Upload Custom Slide Image", select any `.png` or `.jpg` image from your computer, and click Run Slide Screening.
  • Reading the Heatmap: The right image shows where the network's input gradients peaked. Red/yellow areas contributed most to the predicted class; blue areas were ignored.
  • What TTA Agreement means: We run 6 variations of your image (original, horizontal flip, vertical flip, contrast boost, brightness dip, slight blur). `100%` agreement means all 6 variations predicted the exact same disease class.

2. How to Screen a Whole Flock Queue (Tab 2: Batch Flock Table)

  • Click 2. Batch Flock Table in the top navigation bar.
  • The system screens all 4 reference slides in one batch and sorts the table so high-risk detections (`CRITICAL` Newcastle Disease and `URGENT` Coccidiosis/Salmonella) appear at the top of the page above `ROUTINE` Healthy slides.

3. How to Test 2D Convolutions & Autograd (Tab 3: Conv2D & Autograd Test)

  • On the left side, pick a slide and a 3x3 filter (`sobel_edge_x`, `sobel_edge_y`, `laplacian_lesion_detector`, `sharpen_pathology`, or `gaussian_denoise`) and click Apply 3x3 Filter & 2x2 MaxPool to see how edge detection and pooling shrink a `64x64` array to `32x32`.
  • On the right side, change the inputs `x1, x2` or weights `w1, w2, b` and click Run Forward & Backward Pass to see the exact partial derivatives calculated by `ScalarValue.backward()`.

4. Troubleshooting Common Issues

Why does a slide say "MANUAL PATHOLOGIST REVIEW REQUIRED"? Either the top class probability was lower than your "Min Confidence %" box (default 70%), or the 6-pass TTA standard deviation exceeded 8.5%. Lower the threshold to 55% if you want to force an automated call on noisy crops.
How do I call the JSON API from Python or curl? Open Tab 8: REST API Tester (/docs) to test `GET /health`, `GET /metrics`, and `POST /predict` directly inside your browser, or grab the raw OpenAPI spec at /openapi.json.
